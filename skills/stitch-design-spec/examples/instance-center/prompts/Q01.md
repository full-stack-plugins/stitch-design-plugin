[Context]
为演示产品 ExampleConsole 设计实例中心列表 P01，用户任务为只读查找实例并进入详情。Desktop 1280×1024；同时说明 Tablet 768×1024 与 Mobile 390×884 的适配。全中文文案，演示数据不得被理解为真实业务统计。覆盖 normal/loading/empty/error/permission-denied/offline/partial-data。
DESIGN SYSTEM：以下均为教学建议 S3，非已应用远程系统。品牌海蓝 #2563EB 用于主要导航与动作，墨色 #111827 用于正文，白色 #FFFFFF 用于背景，系统无衬线字体；状态必须同时有文字。
[Layout]
1. 共享左侧模块导航与顶部产品栏，主区标题“实例中心”、摘要及“刷新”。
2. 引擎筛选和带可见标签的“搜索实例名称/ID”，保持查询条件。
3. 名称/ID、引擎、节点、健康、运行时间、查看详情的数据表；下方分页。
4. Tablet 收起导航，表格可滚动；Mobile 变为实例卡片，保留名称、健康和详情入口。页面不增加 Agent 侧栏。
[Components]
演示行 demo-instance-01 / ExampleEngine / demo-node-a；数量仅演示。名称或“查看详情”进入同实例 P02，返回恢复搜索、筛选、页码、滚动。筛选改变重置第一页；默认名称升序为建议，实际能力待确认。
首次读取展示骨架，刷新期间禁止重复触发并保留查询；零结果显示“没有匹配实例”和“清除筛选”；读取失败显示“读取失败，重试”，重试同一查询。无权限仅说明并保留导航，不显示可用详情操作。离线显示缓存已过期或无缓存说明；缺失字段显示“暂不可用”，不填 0。键盘顺序随阅读顺序，焦点可见，健康同时显示文本。本页不增加重启、停止、删除。
