[Context]
为演示产品 ExampleConsole 设计只读实例详情 P02，沿用 P01 外壳。Desktop 1280×1024，Tablet 768×1024，Mobile 390×884；全中文，身份 demo-instance-01 为演示。覆盖 normal/loading/empty/error/permission-denied/offline/partial-data。
DESIGN SYSTEM：沿用教学建议 S3；海蓝 #2563EB 用于主要导航与动作，墨色 #111827 用于正文，白色 #FFFFFF 用于背景，系统无衬线字体；这不是远程应用证据。
[Layout]
1. 面包屑“实例中心 / demo-instance-01”，身份、健康与“返回实例中心”。
2. 主体左侧70%依次为运行时、只读配置、关联扩展；右侧30%为健康历史、审计、节点与版本。共享导航保持稳定，不增加 Agent 侧栏。
3. Tablet/Mobile 按运行时、配置、扩展、健康、审计、节点改单列；配置长行受控滚动，返回入口始终可达。
[Components]
运行时提供 CPU/内存的文字摘要、PID/端口；指标没有数据时明确说明，不能制造曲线。配置只读，敏感值遮盖；健康与审计按时间呈现，缺失时间注明未知。“重新读取”只读，“返回实例中心”恢复 P01 搜索/筛选/页码/滚动。
加载为区块骨架；实例不存在显示“实例已不可用”及返回列表刷新；整体错误保留实例身份并提供重试；无权限不泄漏配置；离线标缓存时间或无缓存。部分失败保留可用区块，仅失败区块显示原因与重试。保持键盘顺序、可见焦点和健康文本，无自动业务写入。本次不提供重启、停止、删除。
