# P01 实例列表

## 来源与状态
S1 定义字段；S2/S3 为教学建议，当前为设计草案。

## 职责与边界
支持只读查找与进入详情；不在本页执行重启、停止、删除。共享外壳见设计总览。

## 入口、退出与上下文
入口为导航“实例中心”；名称进入 P02；返回保留引擎筛选、搜索、页码、滚动位置。筛选改变重置到第一页。

## 页面结构
1. 标题“实例中心”、摘要数量和“刷新”。
2. 引擎下拉与“搜索实例名称/ID”。
3. 列表：名称/ID、引擎、节点、健康、运行时间、“查看详情”。
4. 分页与结果数；演示数字明确标注。

## 数据与控件
字段来自 S1；示例 demo-instance-01 / ExampleEngine / demo-node-a。筛选是本地设计合同，不假设接口参数。刷新只读；加载时禁止重复触发；错误不清空搜索词。排序为名称升序的教学建议，真实排序能力待接口核对。

## 状态与恢复
| 状态 | 条件 | 显示/动作 | 退出 |
| --- | --- | --- | --- |
| normal | 查询成功 | 列表与详情入口 | 查看或筛选 |
| loading | 首次读取/刷新 | 骨架；保留查询条件 | 成功或 error |
| empty | 零匹配 | “没有匹配实例”与清除筛选 | 新查询 |
| error | 读取失败 | “读取失败，重试” | 重试原查询 |
| permission-denied | 不可读取 | 权限说明，禁止详情操作 | 返回模块导航 |
| offline | 断网 | 最近数据标记过期；无缓存则说明 | 联网后重试 |
| partial-data | 部分字段缺失 | 缺失标为“暂不可用” | 刷新；不显示为零 |

确认/结果未知不适用：范围内只有只读操作。

## 交互流程
F01：输入→读取→选择→详情→返回。清除筛选恢复默认查询，切换模块退出；出错或离线按上表恢复，不新增业务提交。

## 响应式与无障碍
Desktop 1280×1024 数据表；Tablet 768×1024 可收起导航与表格滚动；Mobile 390×884 卡片并保留健康文本/详情入口。标签常驻，键盘可进入每个实例，状态不只依赖颜色。

## 提示映射与验收
Q01 覆盖以上 7 状态；T01/T03 验收：Given 已筛选到 ExampleEngine 第2页，When 查看详情再返回，Then 筛选/页码/滚动恢复；读取失败重试不丢搜索。状态视觉与接口需后续实测。
