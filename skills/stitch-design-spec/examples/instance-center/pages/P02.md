# P02 实例详情

## 来源与状态
S1 定义详情信息，S2/S3 定义教学布局/恢复建议。草案；不宣称真实服务存在。

## 职责与边界
只读定位实例状态、配置与来源；本次不提供危险操作。复用外壳，无独立 Agent 侧栏。

## 入口、退出与上下文
P01 名称进入，持有选定实例身份；“返回实例中心”恢复列表上下文。实例身份丢失时回列表，不随机选择实例。

## 页面结构
1. 面包屑“实例中心 / demo-instance-01”、身份和健康。
2. 左 70%：运行时 CPU/内存/PID/端口、只读配置、关联扩展。
3. 右 30%：健康历史、审计事件、节点信息与版本。
4. “返回实例中心”；内容区独立滚动，保留导航。

## 数据与控件
S1 定义字段；数据缺失不造曲线或填 0。配置只读且遮盖敏感值，长文本可横向滚动；状态历史按时间顺序，未知时间明确标记。仅“重新读取”和“返回”动作。

## 状态与恢复
| 状态 | 条件 | 显示/动作 | 退出 |
| --- | --- | --- | --- |
| normal | 数据可用 | 详情与来源 | 返回或重新读取 |
| loading | 首次读取 | 逐区块骨架 | 成功/错误 |
| empty | 实例不存在 | “实例已不可用” | 返回列表刷新 |
| error | 整体失败 | 原身份与错误说明、重试 | 重新读取 |
| permission-denied | 无详情权限 | 权限说明，不泄漏配置 | 返回 |
| offline | 断网 | 标明缓存时间，无缓存则说明 | 联网重试 |
| partial-data | 审计或指标单独失败 | 其他区块保留，失败区块重试 | 补齐该区块 |

confirmation/pending/unknown 不适用：当前只读范围没有业务写入。

## 交互流程
F02 见总览：读取→按结果显示→局部/整体重试或返回。不得用整页空白掩盖部分失败。

## 响应式与无障碍
Desktop 1280×1024 使用 70/30；Tablet 768×1024 与 Mobile 390×884 改为运行时→配置→扩展→健康→审计→节点单列。配置保留滚动，无色觉用户可读健康文本；图表有文字摘要，加载反馈可被辅助技术感知。

## 提示映射与验收
Q02 覆盖7状态；T02/T03：Given 审计失败但运行时成功，When 查看详情，Then 保留运行时、审计单独报错并可重试；返回恢复 P01 条件。
